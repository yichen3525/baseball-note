    使用說明

    GPS 定位需要在 HTTPS 網址或本機（localhost）開啟才能使用。手機測試建議把這個檔案放到 GitHub Pages、Netlify 等免費空間。

    打卡範圍是球場 1 公里內，以手機回報的位置計算直線距離。室內或訊號差時定位誤差會變大，可以手動選擇球場。

    比賽資料來自中職官網與野球革命 Rebas，放在 GitHub Pages 時每天自動更新。選好日期和球場，就會帶入對戰球隊、比分、先發投手、勝敗投與 MVP。
